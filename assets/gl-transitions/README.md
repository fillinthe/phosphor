# Bundled gl-transitions

The gl-transitions collection (https://github.com/gl-transitions/gl-transitions, commit e1e4bde9b4dad3cb7bdd7ed28e4b97f469d90448, 2026-10-18):
transitions for clip changes. Each file keeps its own author and licence header (MIT for almost all; two are BSD);
the project's licence is in LICENSE-gl-transitions.txt. Phosphor converts them to ISF transitions when it starts
(phosphor-isf `gltransition`); ones that need a picture of their own are skipped. Where Vidvox's ISF collection
already has the same transition, that copy is used.
