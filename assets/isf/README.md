# Bundled ISF shaders

Vidvox's free ISF collection (https://github.com/Vidvox/ISF-Files, MIT licence: LICENSE-Vidvox-ISF-Files.txt;
each shader's own credits are in its header), at commit 395072d48b3ce7351ccb20a5fda54470591324df (2026-06-04).
Phosphor ships it so every computer has these effects, including Windows and Macs without VDMX. Shaders already
installed elsewhere (VDMX's /Library/Graphics/ISF, your own folders) take precedence over these copies.
