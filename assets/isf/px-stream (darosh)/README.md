# px-stream shaders (by darosh)

From [darosh/px-stream](https://github.com/darosh/px-stream) (MIT OR CC-BY, see LICENSE-px-stream.txt), checked
2026-10-21. Only shaders credited "by darosh" whose code names no other source (no Shadertoy, LYGIA or other ports).

Shipped: Glitch Wave (an audio visualizer) and Curve Ink Scope (an XY oscilloscope: left against right channel,
needs stereo sound). The other XY scopes (X.1–X.5) read a picture of the trace that the author's Max patch draws
with a geometry shader, not the sound itself, so they can't run from an ISF host's audio input.
